# 魔刃行者 / Blade Walker

手機優先的第一人稱自動行走斬魔冒險（手遊 PWA）。

玩家沿**單路**鵝卵石徑前行，魔物會朝主角**衝撞**而來，以角色專屬攻擊擊退之。通關條件：存活至終點並擊殺魔王。
視覺為日系手機 JRPG：高彩度、金框編年卡、明亮丘陵與城堡。第一人稱 3D。地面是一條石徑，不是三線馬路。

## 手機遊玩

1. 用 iOS Safari 或 Android Chrome 開啟公開 https 網址。
2. 直式 9:16 為主；橫向也可玩。
3. 第一次點擊畫面才會解鎖音效與音樂。
4. 戰鬥為單指操作：劍士滑斬、槍手點射、法師長按蓄力。畫面下方約 20% 左右滑動閃避。暫停在右上角。

## 加入主畫面

安裝後可全螢幕、離線再玩（需先成功載入一次）。
iOS Safari：分享，然後選加入主畫面。尚未安裝時標題上方有薄提示。
Android Chrome：選單裡的加到主畫面或安裝應用程式。
清單名稱為魔刃行者，短名魔刃行者，直式獨立視窗。

## 開發與預覽

套件指令為 dev、build、preview。preview 使用連接埠 4173。開發模式用 dev。preview 需 `allowedHosts: true` 並監聽 `0.0.0.0:4173`。

## 操作

全部畫面為繁體中文。觸控為主。空白鍵暫停，結算按 R 重試。
劍士白霜：上方 80% 滑動斬擊，疾斬暴擊。只打近身（地上霜藍圈內）；圈外顯示「距離不足」。
槍手赤煙：上方點擊射擊，頭部額外傷害。
法師蒼焰：上方長按蓄力、放開射擊；蓄滿貫穿爆破；過久潰散。
閃避：在畫面下方約 20% 左右橫滑（短撥即可；此區直滑不會斬擊）。雙指橫滑與鍵盤 A/D 仍可用。側移鏡頭／武器，無敵約 0.38 秒。地面看起來是一條路，沒有三條分道線。岔路凍結時點擊選路，不閃避。
切換到其他 App、鎖定螢幕或切到背景分頁時，戰鬥會自動暫停，返回後由玩家自行繼續。
關卡依序解鎖：暴風小徑、迷霧深林、魔王祭壇。生命 5 格。連擊約 1.2 秒。

## 單路、衝撞、閃避

石徑為一條鵝卵石路。魔物在前方生成後會朝玩家當下的左右位置衝來（不是固定三線飛過）。衝到近處且與玩家左右重疊則受傷；若已閃到一旁，魔物會擦邊衝過螢幕、不受傷。彈幕同樣瞄準玩家，閃避可讓開。史萊姆衝擊波等全路環形彈仍須斬斷，閃避無效。

## 岔路、寶箱、補血

每關石徑會在岔口短暫分成左右（或左中右）再合併回單路。可選 2 或 3 條路，難度不同。選定後鏡頭轉向該側（中路則前衝下沉），並有轉彎視覺特效。
- 緩坡：史萊姆多、補血多。
- 獵道：均衡。
- 死鬥：敵人狠、寶箱多。
- 寶庫：寶箱與南瓜較多。
未選擇則走最緩之路。補血與寶箱：走近同側撿起（攻擊不會撿到；左右離太遠會錯過）。心 +1 生命（上限 5）；寶箱加分與短暫護盾。

## 魔王停步、小魔王

途中小魔王與終點魔王開戰時，自動行走停下，鏡頭停在擂台，進度條暫停。畫面上顯示「小魔王」或「魔王戰」。決戰期間不刷新雜兵（魔王自己的召喚除外）。仍可左右閃避與攻擊。擊殺小魔王後短暫停頓，然後恢復前行。擊殺終點魔王則本關勝利。

- 暴風小徑：約 45% 膠盾騎（小魔王），約 85% 晶黏帝。
- 迷霧深林：約 40% 幽魂長，約 85% 幽靈王。
- 魔王祭壇：約 38% 甲殼副官、約 62% 魔軍尉，約 85% 魔王。

一般敵人另含「射擊哥布林」：鎖定玩家位置後發射直線晶彈，出現在高風險路線與後段獵場；發射後仍可滑動閃避或斬斷彈體。

小魔王血量較低、招式較少（一至兩招），仍會停步決戰。魔王彈幕：晶黏帝衝擊波與晶簇、幽靈王瞬移魂扇與追魂、魔王炮杖蓄力光束與螺旋彈幕。

## 技術

Vite 與 TypeScript 與 Three.js。Web Audio 合成音效。localStorage 存檔。可安裝為 PWA。角色與關卡 3D 資產採背景串流，首頁不再等待全部模型下載。無後端、無內購。
原始碼在 src；執行時立繪與世界繪景在 public/art，保留的 PNG 美術原檔在 design/source-art。
