# REF-AOV — 製作人提供的傳說對決風格針點

**用途：** 品質與感覺對齊，禁止抄角色／UI 圖示／關卡構圖（法律紅線）。  
**圖：** `design/ref-aov/01`～`05`

## 畫面要對上的感覺
1. **角色展示級**：全身穿戴清楚、布料層次、飄帶／裙擺有動勢；不是膠囊、不是塑膠原語。
2. **光與氛圍**：柔光、輪廓可讀、粒子／光暈點綴；背景有場景深度（山、舞台、水、林），不是純色灰盒。
3. **材質厚實**：金屬金邊、紗／布半透、水面折射感——手機上仍要「一眼貴」。
4. **介面**：半透明玻璃面板、細金／青邊、主按鈕發光（金），資訊層次清楚但不搶角色。
5. **我們遊戲仍是直式 9:16 斬魔**；橫版選角／大廳只借「精緻度與層次」，不借 MOBA 佈局照搬。

## 色板方向（給介面 token）
- 底：深藍紫／夜空
- 強調：金（主 CTA）、青／水色（魔法）、血條用高對比紅～粉
- 文字：白＋淡金次級
