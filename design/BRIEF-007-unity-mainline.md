## 決策（製作人拍板）
1. **可玩主線 = Unity Web 試玩**，不是換引擎口號就算過關。
2. **Three.js PWA 降為備援／維護**：未獲總監新令，不開新功能單、不 bump 當主線出貨。
3. **美術標竿仍是傳說對決級**：精緻、好認、手機順；衣服穿在身上（皮帶勒布、袖口塞手套、褲塞靴），材質厚實可讀。**不是**電影光追，**也不是**塑膠低面塊。
4. 現有日光場仍偏陽春塑膠感——**換 Unity 本身不解 BRIEF-006**；角色／魔王／小怪／場景資產要依標竿重做或升級到 Unity 管線。

## 各席
- **主程式（Three.js）：** 凍結主線功能；只修備援崩潰級 bug、或總監點名的拷檔。不再把 Pages 根當 Three.js 首頁。
- **建模／TA：** 新資產預設對 **Unity 主線**；預算與過閘改跟 Unity 管線（總監後續補閘門單）。Three.js 已交鎖定檔未重開單不得覆蓋。
- **策劃：** 玩法變更單標「適用：Unity 主線」；Three.js 僅在備援仍要對齊時另註。
- **品管／法律：** SHIPPED 前仍必過；驗收場改以 Unity 公開試玩為準。舊 Three.js SW 結論不直接當 Unity PASS。
- **特效／配樂：** 新交付對齊 Unity 可播管線；進包前法律綠燈不變。

## 驗收
- 打開根網址 → 進日光場試玩（非 Three.js 標題）。
- `three.html` 仍可進舊版。
