# stip_ult_gun 赤煙絕招

原創一發。玩法 ULT_GUN 0.18 太短，樂句 0.70s 讓耳能認。走 sfxBus。BGM 不停。取代 `ultGun()`。

## 元資料

| 欄 | 值 |
|---|---|
| cue | stip_ult_gun |
| 畫面 | 赤煙扇形彈幕 |
| BPM | —（絕對秒） |
| 拍號 | — |
| 長度 | 0.70s |
| loop | 否 |
| bus | sfxBus |
| 總音量 | 相對 0–1 如下，再乘 sfxBus 0.9 |

## 事件（t_sec 從觸發 0）
